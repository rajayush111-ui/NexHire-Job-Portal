# Job Portal 💼

A simple Job Portal web application built using HTML, CSS, JavaScript, Java Spring Boot, and MongoDB Atlas. This project was developed to learn backend development and frontend-backend integration.

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Java, Spring Boot
* **Database:** MongoDB Atlas

## Features

* Simple and user-friendly interface
* Demo login functionality
* Backend integration with Spring Boot
* MongoDB database connectivity

## Project Structure

```text
Job-Portal/
├── frontend/
├── backend/
└── README.md
```

## How to Run

1. Clone this repository.
2. Start the Spring Boot backend from the `backend` folder.
3. Open the frontend's main HTML file in your browser.
4. Configure the MongoDB connection before running the backend.

## Note

This is a student project, and the login functionality is for demonstration purposes only.
